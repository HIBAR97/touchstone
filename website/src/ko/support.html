iPhone·Mac 기종과 OS 버전, 쓰는 브라우저, 어떤 일이 일어났는지 적어 주세요. API 키나 비밀번호는 보내지 마세요. 답장 시간은 약속드리지 못해요.

자주 묻는 문제

iPhone과 Mac이 연결되지 않아요
  • Mac 메뉴 막대에 Touchstone이 켜져 있고, 두 기기가 같은 Wi-Fi인지 확인해 주세요. 안 되면 USB 케이블로 연결해 보세요.
  • iPhone 설정 > 개인정보 보호 및 보안 > 로컬 네트워크에서 Touchstone을 켜 주세요.
  • Mac 팝업에서 ‘QR 다시 만들기’를 누르고 새 QR을 스캔해 주세요.
연결은 됐는데 커서가 안 움직여요
  • 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 Touchstone을 켜 주세요.
  • 이미 켜져 있다면 껐다 켜고, Touchstone을 종료했다가 다시 실행해 보세요.
웹페이지에 밑줄이 안 보여요
  • 확장 아이콘에서 ‘이 페이지 검사하기’를 눌러 주세요.
  • ‘AI 서비스’와 API 키(또는 로컬 서버 주소)가 맞는지 확인해 주세요. 오류는 확장 팝업에 나와요.
  • ‘틀린 정보를 찾지 못했어요’면 틀린 문장이 없다는 뜻이에요.
iPhone이 진동하지 않아요
  • 확장 아이콘에 ‘Mac과 연결됐어요’가 보여야 해요. 아니면 ‘Mac과 연결’을 누르고 Mac에서 ‘허용’을 눌러 주세요.
  • 커서가 밑줄 친 문장 위에 가만히 멈춰 있어야 해요.
